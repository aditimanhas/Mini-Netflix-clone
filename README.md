🎬 Mini Netflix Clone

A fully responsive Netflix-inspired web application built using HTML, CSS, JavaScript, and OMDb API.

✨ Features:
• User Login & Signup Authentication
• Search Movies & TV Shows
• Movie Details Popup
• Trailer Video Popup
• Add to My List ❤️
• Responsive Netflix UI
• Dynamic Movie Sections
• LocalStorage Authentication & Favorites

🛠 Technologies Used:
HTML5 • CSS3 • JavaScript • OMDb API • Font Awesome

This project helped me improve my frontend development skills, API handling, DOM manipulation, localStorage, and responsive UI design.

🚀 More features and improvements coming soon!
